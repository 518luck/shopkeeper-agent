# app/agent

适用：LangGraph 智能体工作流，例如图定义、状态、运行上下文、模型与节点。

```text
graph.py     定义图。只做四件事：声明 schema、注册节点、连边、compile；节点名与函数名一致；
             分支用条件边；新增或删除节点后同步这里的注册、连边与 demo() 的 state 构造
state.py     定义状态。TypedDict，只放节点间传递的业务数据（查询、关键词、召回结果、提示词
             上下文、SQL、错误）；不放仓储与客户端；节点会写入的字段在入口处置空值
context.py   定义运行上下文。只声明节点执行时的外部依赖，不实例化，由接口层组装注入；
             字段名即 runtime.context 的键名；新增依赖后同步接口层组装
llm.py       定义模型。唯一模型入口，节点只 import 它，不自行初始化
nodes/       定义各节点。一节点一文件、文件名与节点名一致；签名固定 (state, runtime) 且
             两个参数名不改；只返回局部更新；依赖只从 runtime.context 取，不引用其它节点；
             提示词用 load_prompt 读取
```

以上是最小结构，非必要不要新增结构
